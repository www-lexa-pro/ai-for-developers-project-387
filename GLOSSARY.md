# Календарь звонков

Сервис записи гостей на встречи с одним заранее заданным владельцем календаря.

## Термины

**Владелец календаря**:
Человек, с которым гости бронируют встречи. В приложении один владелец;
он создаёт типы встреч и просматривает предстоящие встречи.

**Гость**:
Человек, который без регистрации выбирает тип встречи и время, указывая
своё имя и email для записи.

**Тип встречи**:
Вариант встречи с названием, описанием и длительностью, который гость
выбирает перед записью.

**Слот**:
Интервал для встречи выбранного типа с конкретным началом и окончанием.
Его длительность совпадает с длительностью типа встречи.

**Бронирование**:
Подтверждённая запись гостя на встречу выбранного типа в конкретное время.

**Окно записи**:
Период из 14 календарных дат, в пределах которого гость может выбрать
свободный слот; начинается с завтрашнего дня по московскому времени.

**Шаг начала встреч**:
Расстояние между предлагаемыми началами встреч: 30 минут от начала
рабочего дня, независимо от длительности типа встречи.
