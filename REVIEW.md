# Критерии ревью календаря

Оставляй только замечания о проблемах, внесённых этим изменением. Для каждого
замечания укажи файл и строку в diff, затронутый сценарий и конкретное последствие.
Если таких замечаний нет, сообщи об этом.

- Проверь, что гость видит только допустимые слоты и что расчёт расписания и окна
  записи использует московское время.
- Проверь отказ при пересечении бронирований, включая встречи разных типов и
  одновременные запросы. Соседние интервалы могут соприкасаться границами.
- Проверь совместимость API с существующими клиентами и согласованность изменений
  TypeSpec с перегенерированными контрактами Go и TypeScript.
- Проверь, как изменение влияет на данные уже созданных бронирований и типов
  встреч. Приложение хранит их в памяти процесса.
- Проверь тесты видимого поведения гостя и владельца календаря для изменённых
  сценариев, включая уместные случаи ошибок.
