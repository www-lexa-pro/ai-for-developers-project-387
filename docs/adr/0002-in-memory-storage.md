# Хранение данных в памяти одного экземпляра

Для учебной версии выбрано разрешённое заданием хранение типов встреч и
бронирований в памяти одного экземпляра приложения. При перезапуске
бронирования и созданные владельцем типы сбрасываются, а приложение заново
создаёт три начальных типа. Сброс данных описан в README.
