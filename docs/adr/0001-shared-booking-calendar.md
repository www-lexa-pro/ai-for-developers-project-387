# Единый календарь для всех типов встреч

Все типы встреч занимают время одного владельца, поэтому сервер проверяет
пересечение с бронированиями всех типов, включая частичное наложение. Проверка
пересечений и создание записи выполняются вместе под общей блокировкой
календаря, чтобы из одновременных запросов на пересекающиеся интервалы прошёл
только один. Начало следующей встречи может совпадать с окончанием предыдущей.
