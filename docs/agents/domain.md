# Документы предметной области

Используем единый контекст проекта:
- GLOSSARY.md в корне — словарь терминов.
- docs/adr/ — важные решения и их причины.

Перед изучением предметной области прочитай словарь и относящиеся
к задаче решения. Используй термины словаря в задачах, коде и тестах.
Противоречия с существующими решениями явно выноси на обсуждение.

Если документов пока нет, продолжай работу. Создавай их по мере
согласования терминов и решений через domain-modeling.
